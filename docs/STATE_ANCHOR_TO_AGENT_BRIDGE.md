# State-anchor evidence and its Agent interpretation boundary

## Status and evidence-version boundary

This document connects a completed materials analysis to the Agent V5 measurement-admissibility design, but the chronology must remain explicit.

The frozen Condition-A Agent V5 series on the implementation branch was run **before** the state-anchor bridge analysis was added to the active scientific tool. Those runs used the earlier chemistry-audited rheology tool output (tool version `3.5-verified-phosphoric-perturbation`) and therefore did **not** receive the 1.824x -> 1.086x state-anchor information-gain result.

The state-anchor information-gain statistic is retained as a materials/statistical analysis. It is deliberately excluded from the current model-visible Agent tool output and must not be treated as a decision-time Agent input.

## 1. Materials question

The local state-conditioned rheology result shows that nominal formulation identity does not uniquely locate the viscosity level realized in one experiment.

The bridge analysis asks a narrower question:

> When the nominal formulation is already known, how much additional predictive information is supplied by one state-specific viscosity measurement?

E2 is the only chemistry-audited nominal formulation with multiple realizations, so the comparison is intentionally restricted to repeated E2 realizations.

## 2. Same-formulation holdout design

For each of the four audited E2 realizations:

1. hold that realization out;
2. retain the other E2 realizations, so formulation identity remains represented in training;
3. fit a formulation-only quadratic inverse-temperature model on the remaining data;
4. independently fit the shared state-conditioned quadratic thermal shape on the remaining data;
5. compare two predictions for the held realization at 120 and 130 °C:
   - formulation-only prediction, with no measurement from the held realization;
   - one-anchor state calibration using the held realization's measured 110 °C viscosity.

The thermal basis is held constant so the comparison isolates state information rather than model flexibility.

## 3. Result

Across four held realizations and eight target predictions:

| Quantity | Result |
|---|---:|
| formulation-only multiplicative RMSE | 1.824× |
| one-anchor multiplicative RMSE | 1.086× |
| log-RMSE reduction | 86.2% |
| realization-cluster bootstrap 95% interval for log-RMSE reduction | 75.0–97.3% |

The result files are:

```text
derived/state_anchor_bridge/same_formulation_anchor_110_to_120_130.csv
derived/state_anchor_bridge/state_anchor_bridge_summary.json
```

and are regenerated by:

```bash
python scripts/state_anchor_bridge_analysis.py \
  --output-dir derived/state_anchor_bridge
```

## 4. Scientific interpretation

The result separates two information sources:

```text
nominal formulation identity
        |
        | does not reliably locate
        v
realized viscosity level

one in-domain viscosity anchor
        |
        | supplies state information
        v
short-range thermal-response reconstruction
```

The anchor is therefore not merely another temperature point. It is an observation of the hidden viscosity-scale state.

This result remains local. It quantifies the value of state calibration **conditional on a valid shared thermal shape**.

## 5. Relation to Agent measurement semantics

The measurement catalog already distinguishes:

- `M-ANCHOR`: state calibration;
- `M-SWEEP`: direct thermal-shape verification;
- `M-HOLD-120`: direct observation of thermal-hold drift;
- `M-REPEAT`: realization/process-state control.

The bridge analysis gives quantitative support to the physical interpretation of what an anchor measurement observes: realized viscosity-state information inside the validated local chemistry domain.

This statistic is **not** supplied to the Agent. The Agent measurement catalog remains grounded in the broader, previously established state-conditioned rheology and chemistry-domain logic rather than in this later numerical comparison.

The result does not imply that `M-ANCHOR` is universally admissible.

## 6. Connection to the pre-registered Agent V5 chemistry-domain gate

The V5 applicability rule is measurement-specific:

```text
candidate chemistry
      |
      v
assess_shared_shape_applicability(candidate)
      |
      +-- shared_shape_use == allowed_with_state_anchor
      |          |
      |          +--> M-ANCHOR may be admissible
      |
      +-- chemistry shifted / no verified direct sweep
                 |
                 +--> M-ANCHOR inadmissible
                 +--> M-SWEEP remains admissible and is the required verification
```

The material analysis and the Agent rule are therefore related but not identical. The bridge analysis quantifies the physical information content of an anchor, while the Agent applicability rule determines when use of the shared-shape shortcut is scientifically admissible. The bridge statistic itself is not part of the Agent payload.

## 7. V5 information-parity requirement

Within any one evidence version, the two primary V5 arms must receive identical model-visible scientific information before enforcement.

For the already-frozen Condition-A series, both arms received the same version-1 chemistry-audited tool output and the same applicability audit. The recorded pre-enforcement payload hash was identical across arms. The state-anchor bridge result was not part of either arm.

Future Agent series should continue to use the declared Agent evidence contract without the later state-anchor information-gain statistic unless the author explicitly authorizes a new design.

The causal interpretation remains:

> within a fixed Agent evidence contract, any arm difference should be attributable to converting the same scientific knowledge from advice into executable policy, not to unequal scientific information.

## 8. Manuscript role

The completed state-anchor bridge analysis may be reported as a materials analysis because it is derived from the chemistry-audited local measurements. It strengthens the physical interpretation of why an anchor measurement can carry state information.

The bridge statistic should be reported for its scientific meaning: it quantifies the information carried by a state-specific anchor. Agent results should be reported from the evidence actually used at decision time, without importing this later statistic into the causal account of those decisions.

## 9. Claim boundary

Supported:

- formulation identity alone can leave large uncertainty in realized viscosity level;
- one 110 °C state anchor materially improves 120–130 °C reconstruction within repeated E2 realizations;
- this provides direct empirical justification for an anchor-type measurement inside validated shared-shape support;
- the chemistry-domain boundary determines whether that shortcut is scientifically admissible.

Not supported:

- universal one-point calibration across reactive-PUR chemistries;
- using the local anchor result to skip a temperature sweep after resin modification or other chemistry shift;
- interpreting future V5 behavior before the pre-registered comparison is actually run and audited.

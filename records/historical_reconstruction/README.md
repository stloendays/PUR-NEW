# PURNEW_REC_R1 — reconstructed historical recommendation record

This directory stores a **retrospective reconstruction** of the author-confirmed pre-result PUR-NEW recommendation. It is not presented as the contemporaneous machine-readable freeze artifact.

## Historical boundary

The research team confirms that the Agent selected the validation formulation before the corresponding wet-lab outcome was known to the Agent. The original contemporaneous Git commit, API timestamp, run ID, prompt hash, input hash, and exact model identifier have not been recovered, so they are not fabricated in this reconstruction.

The current Git commit timestamps only the upload of this reconstructed record. It must not be used as evidence for the historical recommendation time.

## External-evidence percentage basis

Percentages reported by external literature/patent sources are retained on their **source-reported basis** and are used as coarse analogue anchors. They are not treated as numerically identical to total-formulation wt% unless denominator equivalence is explicitly established.

Accordingly, the selected 14.00 wt% acrylic-like and 4.12 wt% tackifier-like levels are described as **close to / adjacent to** independently documented modifier regions, not as exact percentage-basis matches.
